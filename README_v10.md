# 神獸紀元 — 窮奇 Boss v10 戰鬥整合原型

## 執行
使用 Godot 4.x 匯入 `project.godot`，執行 `Battle.tscn`（主場景）。原本的 `Preview.tscn` 和 v9 骨架素材保留供比較。

## 操作
- **滑鼠左鍵**：點擊紅色圓圈攻擊翅膀弱點（每次 -65）。翅膀生命值降至 0 後窮奇落地。
- **A**：手動觸發一次防禦塔射擊；防禦塔每 0.9 秒自動射擊。
- **D**：空中俯衝，觸發後對城牆造成傷害。
- **F**：翅膀破壞後封印窮奇（或點擊封印圈）。
- **R**：重置戰鬥。
- v9 原有 1–6 動作快捷鍵仍可用於除錯。

## 戰鬥參數（本次原型新增，非原企劃的確定數值）
- Boss HP 1200；翅膀 HP 300；城牆 HP 500。
- 防禦塔 0.9 秒一次，空中傷害 24，落地傷害 38。
- 翅膀破壞後可封印；封印獎勵 +20% 對空傷害目前僅為旗標文字，**未實作永久升級系統**。
- 攻擊與俯衝傷害透過 v9 既有訊號連接。

## 已知限制
- 本版是可供 Godot 匯入與驗證的原型工程，**尚未實際在 Godot 執行測試**。
- 沿用 v9 剛性分層骨架，無權重蒙皮；接縫與缺損美術尚未完全解決。
- 塔、防禦城牆、弱點圈、封印圈是程式繪製的測試佔位圖；非正式美術。
- 攻擊範圍和弱點目前為畫面座標點擊判定，不是 Area2D 物理碰撞。
- 封印後的長期塔加成、波次與敵人尋路尚未整合。
